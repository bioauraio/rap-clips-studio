Выводы

Наши козыри

  • Клип под собственный трек с нарезкой по дорожке — ниша не занята никем из тринадцати.
  • Цена конкурентна: Seedance Mini ~$0.5 и Kling ~$0.8 — уровень Higgsfield, дешевле OpenArt, втрое дешевле Союзлаба (у них Seedance-ролик ~350₽).
  • Партнёрка токенами в два уровня — в таком виде нет ни у кого.
  • Агент проекта — на уровне лидеров (Krea Node, OpenArt Director, «Suprecomputer» Союзлаба).

Три дыры

  • Remix / шаринг — двигатель роста у OpenArt, ImagineArt, gVideo. У нас нет вовсе.
  • Veo — есть у всех одиннадцати платформ; kie отдаёт Veo 3 Fast от $0.30 — подключение почти бесплатно по трудозатратам. Заодно Wan (дешевейшее видео, $0.10–0.25).
  • MCP / API — Higgsfield, OpenArt, ImagineArt и даже Союзлаб дают звать себя из Claude и других агентов.

Источники: официальные страницы цен (openart.ai, fal.ai, replicate.com, gvideo.ai, domoai.app, kie.ai, soyuzlab.ai, magnific.com) и обзоры 2026 года там, где тарифы скрыты за логином (Krea, Higgsfield, Pollo, SYNTX). «?» = проверить не удалось, оценки цен за клип — на среднем тарифе сервиса.
