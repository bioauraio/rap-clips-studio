# Основное окно генерации — эталоны и решения

Владелец прислал два интерфейса как образец: **SYNTX** (общая раскладка окна) и
**Higgsfield** (панель параметров). Плюс отдельное требование по тону нашего стиля.

## 0. Главное требование по стилю

> «делай в нашем стиле и минималистично, чтобы глаза не выедал этот наш дизайн яркий»

Это разворот тона, а не отмена системы. Наш огонь остаётся марочным цветом, но
перестаёт заливать интерфейс. Правила для этого окна:

- **Огонь только на ОДНОМ элементе экрана** — кнопке запуска. Всё остальное:
  картон, обводка, приглушённый текст.
- Обводки тоньше: 1px вместо 1.5–2px на вложенных элементах; офсетные тени
  только у кнопки запуска и у карточек верхнего уровня.
- Заливки — `--inset` и `--card`, без градиентов. Градиент во всём окне ровно один.
- Активное состояние показываем **обводкой и весом текста**, а не заливкой огнём.
  Чипы, вкладки, выбранные параметры — тёмная рамка плюс полужирный, без фона.
- Подписи параметров — мономодуль 10.5px, приглушённый цвет; значения — обычный
  текст цвета `--text`. Не капслочить всё подряд.
- Рабочая область (галерея работ) — самая спокойная зона: бумага, тонкие рамки,
  никаких акцентов, кроме статуса генерации.

## 1. Панель параметров (эталон Higgsfield)

Порядок сверху вниз — это порядок работы, и он сохраняется:

| Блок | Что делает | Наше решение |
|---|---|---|
| Вкладки `Create / Edit / Motion Control` | три задачи над видео | у нас: **Создать · Правка · Движение**; «Правка» и «Движение» показываем только там, где движок это умеет, иначе гасим с подсказкой |
| Карточка пресета с превью + `Change` | выбранный стиль/пресет с картинкой | наш стиль или каркас с превью и кнопкой «Сменить» |
| Табы `References / Extend Video` | что прикладываем | **Референсы · Продлить** — продление берёт последний кадр предыдущего ролика |
| Зона `Add references` (Image, Video, Audio) | приём вложений тремя иконками | у нас четыре ВИДА референса: вайб, стиль, локация, копия (уже в бэкенде), плюс аудио для музыкальных режимов |
| `Prompt` с подсказкой и `@Elements` | текст + вставка объектов | подсказка-пример обязательна; `@` вставляет персонажа из библиотеки по имени — у нас персонажи уже привязаны к аккаунту |
| Переключатель звука `On` | генерить ли звук | у нас **по умолчанию выключен**: сверху ложится трек пользователя, лишняя дорожка — мусор и деньги |
| `Model` с индикатором качества | выбор движка | наш список из /api/providers: цена в токенах, доступность по ключам и тарифу, недоступное **погашено с причиной** |
| Ряд `5s · 16:9 · 1080p` | длительность, формат, качество | тот же ряд; значения ограничены возможностями выбранного движка (Kling берёт только 5 или 10 секунд — показываем правду) |
| `Bitrate: High` | качество потока | у нас не нужен: битрейт задаём сами при сборке. НЕ копируем. |
| Кнопка `Generate` с ценой | запуск и стоимость | **единственный огненный элемент экрана**; цена в токенах на самой кнопке, до нажатия |

## 2. Раскладка окна (эталон SYNTX + правка владельца)

```
┌──────────┬─────────────────────────────────────┬──────────────┐
│ история  │        РАБОТЫ (галерея)             │  параметры   │
│ и проекты│  сетка готовых картинок и роликов   │  (см. §1)    │
│ поиск, + │  новое — сверху, статус на карточке │              │
└──────────┴─────────────────────────────────────┴──────────────┘
```

- **Слева** — история и проекты, поиск, «+». Пустое состояние честное.
- **Центр — РАБОТЫ, а не одна генерация.** Владелец сказал прямо: «справа работы
  которые сгенерил». Сетка карточек: превью, движок, цена, время, действия
  (в проект, оживить, повторить, скачать, удалить).
- **Справа** — панель параметров из §1.
- На мобиле: панель уезжает в нижнюю шторку, галерея занимает экран.

## 3. Чего из эталонов НЕ берём

- **Тёмную тему.** У нас тёплая бумага; копировать чёрный фон значит выбросить марку.
- **Кислотный акцент** (лаймовый у Higgsfield, жёлто-зелёный у SYNTX). Наш акцент
  один и оранжевый, и его в окне ровно столько, сколько на кнопке запуска.
- **Bitrate** — параметр ради параметра, мы задаём его сами.
- **Витрину моделей на пол-экрана.** У них продукт — доступ к моделям, у нас —
  готовый клип. Модель выбирается в панели, а не является главным героем.
- **Молчаливые ограничения.** Там закрытая по тарифу модель выглядит доступной;
  у нас она погашена и объясняет причину.
