Владелец прислал три экрана конкурента как образец. Что берём, что нет.

## 1. Экран чата

```
┌──────────────────────────────────────────────────────────────────────┐
│ ЛОГО │ Главная  Supercomputer │ [Чат] Изображения Видео Аудио …      │ Активные │ + Тарифы │ (RI) │
├────────────────┬─────────────────────────────────────────────────────┤
│ ⊕ Новый чат    │                                                     │
│ ⌕ Поиск чата   │              ✦                                      │
│                │      ЧЕМ ЗАЙМЕМСЯ СЕГОДНЯ?                          │
│ Сегодня        │                                                     │
│  (Нет чатов)   │   ┌───────────────────────────────────────────┐     │
│                │   │ Этот чат: 0 · Все текстовые: 0            │     │
│                │   │ Начните писать текст…                     │     │
│                │   │                                           │     │
│                │   │ [+]  [🅰 Claude Opus 4.7 ▾]      Auto  (↑)│     │
│                │   └───────────────────────────────────────────┘     │
│                │   Ответы оплачиваются по фактическому использованию.│
└────────────────┴─────────────────────────────────────────────────────┘
```

**Что забираем:**
- **Переключатель модели ВНУТРИ поля ввода**, а не отдельной панелью сверху. Рядом
  кнопка «+» (вложения) и режим «Auto». Компактно и не отвлекает.
- **Счётчик расхода прямо над полем**: «Этот чат: N · Все текстовые: N». Человек видит,
  во что ему обходится разговор, не уходя в кабинет.
- **Честная строка про оплату** под полем: «Ответы оплачиваются по фактическому
  использованию. Итог может быть выше прогноза.» Мы обещали не врать про цену — это
  ровно та формулировка, которую не стыдно написать.
- **Сайдбар**: «Новый чат», «Поиск чата», история, сгруппированная по датам («Сегодня»),
  пустое состояние честно пишет «Нет чатов».
- Крупный вопрос по центру вместо пустого экрана. У нас будет свой текст.

**Что НЕ берём:** тёмную тему и кислотные акценты — у нас свой светлый картон;
разделение на «Чат / Изображения / Видео / Аудио» отдельными разделами верхнего меню —
владелец просил ОДНО окно, где переключается модель, а не четыре вкладки.

## 2. Тарифы

Start 1490 ₽ (300 кредитов) · Plus 3490 ₽ (800) · Pro 5090 ₽ (1200) ·
Ultra 10590 ₽ (2600, с ползунком 2600 / 5200 / 7800). Везде «−30%» и зачёркнутая цена.

**Главный приём, который стоит забрать целиком** — расшифровка кредитов в человеческих
единицах прямо в карточке:

```
300 кредитов/мес
= 150 генераций Nano Banana 2
= 100 генераций GPT Image 2
= 4 видео Seedance 2.0 720p, 5 сек
```

У нас уже есть строка «≈ 2 клипа по 3 минуты», но одной строкой. Надо давать разбивку
по движкам — человек сразу видит, что 154 очка за сцену на Seedance 2.5 это дорого,
а 4 очка на Grok — нет.

Ещё оттуда: **ползунок объёма на верхнем тарифе** (2600 / 5200 / 7800) — один тариф,
три ёмкости. Это проще, чем городить пятый тариф.
И приписка мелким внизу с точным расчётом: «Nano Banana 2 — 2 кредита за генерацию,
GPT Image 2 — 3 кредита, Seedance 2.0 720p 5 сек — 75 кредитов».

## 3. Экран согласий при входе

Три чекбокса: обязательное соглашение + политика + согласие на обработку ПД (со звёздочкой),
отдельно аналитические cookie, отдельно маркетинговые рассылки. Ошибка красным:
«Примите обязательные условия, чтобы продолжить».

**Забираем разделение согласий**: обязательное — одно, остальные необязательные и по
умолчанию ВЫКЛЮЧЕНЫ (у них включены — так делать не будем). Нам это понадобится, когда
включим приём платежей: оферта и обработка персональных данных должны быть приняты явно.
