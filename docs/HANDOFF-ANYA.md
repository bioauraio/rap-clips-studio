## Что это за продукт

**lolq.ai** — студия ИИ-клипов: человек загружает трек, система режет его
на сцены, рисует кадры, оживляет видео-движками и собирает клип. Плюс
режимы: UGC, мокапы, ИИ-блогеры, сериалы, Тренды («фото → ролик» по
шаблону), Заработок (партнёрские продукты со ссылками), Музыка
(генерация/мастеринг/стемы), Генератор (чат-песочница с агентом).

Грабли деплоя (все собраны кровью):
- **rsync `backend/ frontend/` одной командой в общий каталог сливает всё
  в корень** — файлы лягут россыпью, сервер продолжит работать на старом
  коде, а deploy скажет «ok». Только по подпапкам.
- Статика ПЕЧЁТСЯ В ОБРАЗ: поменял frontend — нужен `--build`, простой
  restart не подхватит.
- На lolq пересобирать только `qlolvideo` — рядом чужие проекты
  (podsoznanie, rod), их не трогать.
- SSH до серверов ФЛАПАЕТ — всё делать ретраями (3–5 попыток с паузой).
- Версия статики: в `frontend/index.html` все ссылки `?v=N` — при правке
  js/css поднять N, иначе браузеры держат старое. index.html отдаётся с
  no-cache — это уже настроено.
- 25.08 msk падал целиком (вероятно память): если ВСЕ *.resetaura.io
  отвечают 000, а ping идёт — жёсткая перезагрузка из панели Timeweb.

## Архитектура кода

- `backend/main.py` — ядро (12k строк): проекты/треки/сцены, генерация,
  токены-касса, тарифы, тренды, заработок, вебхуки. Роут-порядок важен:
  всё регистрируется ДО `app.mount("/")`.
- `backend/mediagen.py` — движки: VIDEO_ENGINES/IMAGE_ENGINES (реестры),
  kie.ai (createTask/recordInfo), Veo — ОТДЕЛЬНЫЙ endpoint
  `/api/v1/veo/generate`, шлюзы ChatGPT/Grok, сборка клипа ffmpeg.
- `backend/chat.py` — Генератор + агент проекта (`/api/chat/agent`):
  бесплатные правки (стиль/тексты/трек) применяет сервер, платное — кнопками.
- `backend/crm.py` — админка: клиенты, рассылки, наценка, дизайн-токены,
  тумблеры моделей, фиксация продаж Заработка.
- `backend/music_api.py` — раздел Музыка (генерация Suno-фолбэком, мастеринг
  по эталону, анализ+тональность, релиз-пакет). `music.py` — Suno/стемы/
  мастеринг/тональность. `audio_analysis.py` — темп (numpy).
- `backend/voice.py` — озвучка ElevenLabs (ждёт ключ).
- `backend/db.py` — SQLAlchemy/SQLite. База на томе `/data/`.
- `frontend/` — ванильный JS: `app.js` (студия), `sections.js` (навигация,
  Тренды, Заработок, Академия), `mode-menu.js`+`modes.js` (режимы),
  `music-studio.js`, `i18n.js` (EN/RU — ВСЕ тексты только через словарь).
- `admin/` — отдельная SPA админки.

## Экономика (не сломай!)

- Токены: `_move_points` в main.py — ЕДИНСТВЕННАЯ дверь движения токенов,
  всегда пишет журнал PointEvent. Не двигать балансы мимо неё.
- Коины: бонусы = своя валюта, 1 коин покрывает `BONUS_RATE` (0.68) токена,
  сгорают первыми. Логика применения одна на основную ветку и фолбэк.
- Наценка: коэффициент в админке («Наценка»), ценники FRAME_COST/VIDEO_COST
  ЖИВЫЕ (пересчитываются) — не кэшировать их значения.
- Заработок: продажа фиксируется в CRM (`/api/admin/earn/sale`), client_key
  УНИКАЛЕН — «оплачивается только первая покупка клиента» держится базой.
- ЮKassa: магазин 1441743, вебхук lolq.ai/api/billing/webhook работает.
  Рекуррентка НЕ включена ЮKassa-менеджером — оплата тарифа автоматически
  падает на разовую (фолбэк в коде). Stripe — ключей нет.

## Внешние каналы

- **kie.ai** — главный поставщик (Seedance/Kling/Veo/Nano Banana/Suno).
  Ключ в `infra/.env` (KIE_API_KEY). Баланс: GET /api/v1/chat/credit.
  Файлы отдаём kie ПОДПИСАННОЙ ссылкой `/pub/{token}` или jpeg-копией в
  outbox — kie НЕ принимает webp и не имеет upload-endpoint.
- **Шлюзы подписок** (бесплатные, на msk): ChatGPT :8766, Grok :8767,
  Claude/agent :8765, STT :8787. С lolq доступны через туннель на
  172.19.0.1 (systemd `qlol-gateways-tunnel`). Это Playwright-браузеры:
  медленные, таймаут в mediagen 420с. `/health` может врать — проверяй
  реальным вызовом.
- **Grok-аккаунт**: куки в `/opt/claude-agents/openai/grok_cookies.json`
  (аккаунт Bio Aura). Видео упирается в usage-лимиты аккаунта: «not
  rendered within 300s» почти всегда = лимит/оплата, шлюз теперь сам
  пишет причину.
- **Spaceship (домены)**: ключи в `infra/.env` на msk
  (SPACESHIP_API_KEY/SECRET). API: spaceship.dev/api/v1, заголовки
  X-Api-Key/X-Api-Secret. С серверов РФ ходить через socks5
  172.18.0.1:1081 (Cloudflare режет). ВНИМАНИЕ: в паре КОРОТКАЯ строка —
  key, ДЛИННАЯ — secret.
- **YouTube-треки**: yt-dlp в образе, ветка в `/audio/from-url`.

## Правила, о которые уже спотыкались

- Персонажи: имена в промптах кадров — при смене персонажей имена
  меняются автоматически, но ОПИСАНИЕ внешности переписывает только
  кнопка «Написать промпт». Сгенерённые развороты (webp, kind=model) НЕ
  идут референсами — только живые фото.
- FastAPI: новый роут может уронить сервис на импорте — после каждой
  правки проверяй `python3 -m py_compile` и healthcheck.
- Правки строк питоном: если `assert old in s` падает — сначала grep
  фактического текста, файл может отличаться на слово.
- Никогда не «улучшай» чужие проекты на 5.42.120.67 и не compose up без
  имени сервиса.

## Параллельная работа (Аня + владелец + Claude)

Канон кода — GitHub `bioauraio/rap-clips-studio`. Сервер — только цель
выкатки, код там руками не правим (rsync --delete всё равно затрёт).

Цикл (одинаковый у всех):
1. `git pull --rebase origin main` — ПЕРЕД началом работы и перед push.
2. Правки → commit небольшими порциями с внятными сообщениями.
3. Деплой одной командой: `./scripts/deploy.sh ~/.ssh/anya_lolq_key`
   — сам пуллит/пушит и откажется выкатывать, если main не втянут или
   есть незакоммиченное. Это защита, не обходить.
4. Конфликт при rebase = мы правили одно место: конфликт решаем в коде,
   ничего не «восстанавливаем» rsync'ом с сервера.

Границы, чтобы не мешать друг другу:
- Большие параллельные куски — в ветках `anya/<тема>`, merge в main
  когда готово; мелочь можно прямо в main через rebase-цикл.
- Секреты (.env, ключи kie/YooKassa/бота) в git не кладём — они живут
  только на серверах.
